# mixmaster-local: правила проекта

Локальный бесплатный инструмент для сведения и мастеринга музыки. Автор и единственный пользователь: Денис (музыкальный продюсер). Полное описание задачи в PROMPT.md.

## Жёсткие ограничения

- Всё работает локально и офлайн. Никаких облачных сервисов, платных API, API-ключей и подписок
- Только open-source зависимости (Matchering, Pedalboard, pyloudnorm, scipy, numpy, soundfile, Gradio, matplotlib)
- Проект под GPLv3 (Matchering и Pedalboard под GPLv3)
- Исходные файлы пользователя никогда не перезаписывать: результаты только в outputs/

## Стиль и язык

- Интерфейс и сообщения об ошибках на русском
- Код и комментарии на английском, докстринги короткие
- Модульная структура: core/ (логика), presets/ (JSON), app.py (интерфейс), tests/
- Параметры обработки хранить в пресетах, не зашивать в код

## Аудио-правила

- Внутри пайплайна 44100 Гц, float32; экспорт 24 бита (опционально 16 бит и MP3)
- Перед мастером оставлять минимум 3 дБ headroom на сумме
- Для A/B-сравнения выравнивать громкость, чтобы «громче» не воспринималось как «лучше»
- Измерения громкости через pyloudnorm (ITU-R BS.1770)
- Большие файлы обрабатывать без падений по памяти

## Рабочий процесс

- После каждого шага запускать тесты и проверять на синтетическом аудио
- Не делать git-коммиты без просьбы пользователя
- Решения по умолчанию записывать в README, пользователя без нужды не отвлекать
