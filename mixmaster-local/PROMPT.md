# Задача: локальный инструмент для сведения и мастеринга треков

Прочитай CLAUDE.md и этот файл целиком, затем собери проект в текущей папке. Костяк (папки, пресеты, заглушки модулей) уже лежит здесь: развивай его, а не пиши с нуля.

## Цель

Я закидываю в интерфейс свой вокал (WAV) и бит, плюс референс-трек в нужном звучании в хорошем качестве. Инструмент сам сводит, обрабатывает и мастерит трек под референс. На выходе готовый WAV 24 бита. Всё локально, бесплатно, без облаков, без платных API и без API-ключей. Использование личное, продавать и масштабировать не планируется. Нужен рабочий инструмент с удобным интерфейсом.

Контекст: я музыкальный продюсер (synthwave / trap / рэп / рок), вокал на русском, английском и литовском, в стиле ближе к Kai Angel. У меня много материала для тестов.

## Стек (всё бесплатное, open-source)

- Python 3.10–3.12 (Matchering и его зависимости могут не собираться на 3.13: сначала проверь, при проблемах используй venv на 3.12)
- Matchering (мастеринг по референс-треку), GPLv3
- Pedalboard от Spotify (EQ, компрессор, лимитер, реверб, delay, фильтры), GPLv3
- pyloudnorm (LUFS), numpy, scipy, soundfile
- Gradio для интерфейса в браузере, matplotlib для графиков
- Проект оставь под GPLv3, положи LICENSE

## Режимы

1. **Свести вокал + бит и сделать мастер по референсу** (главный режим)
   - Входы: вокал WAV, бит WAV, референс WAV (загрузка или выбор из папки references/)
   - Шаги: анализ → вокальная цепочка → обработка бита под вокал → баланс → сумма → мастер Matchering
2. **Мастер готового трека по референсу**
   - Вход: один WAV (уже сведённый трек) + референс
   - Анализ → лёгкая подготовка → Matchering
3. **Мастер без референса**
   - Цепочка Pedalboard с пресетом и целевой громкостью (LUFS)

## Шаг 1. Загрузка и анализ

- Читай WAV через pedalboard.io.AudioFile, приводи всё к 44100 Гц и float32, стерео (моно вокал дублируй в стерео после обработки)
- Для каждого файла считай: integrated LUFS, true peak, динамический диапазон (LRA), баланс частот по 6–8 полосам (sub, bass, low-mid, mid, presence, high, air)
- Валидируй вход: нормальный формат, не тишина, нет сильного клиппинга; если проблема, показывай понятное предупреждение
- Показывай числа в интерфейсе до и после обработки

## Шаг 2. Вокальная цепочка (режим 1)

Порядок: high-pass → коррекция low-mid → компрессор → де-эссер → presence/air → пространство (reverb + delay)

- High-pass около 80 Гц (из пресета)
- Адаптивный EQ: сравни спектр вокала с целевой кривой пресета (или с вокалом референса, если выбрано), корректируй в пределах ±3 дБ. Мягкие срезы в области 250–400 Гц при «бубнении», подъём presence 3–5 кГц, air shelf от 10 кГц, всё через PeakFilter / HighShelfFilter
- Компрессор: порог выводится из уровня вокала (например, по перцентилям огибающей), ratio и атака/релиз из пресета, при сильных пиках добавь второй, более быстрый компрессор
- Де-эссер: самостоятельная реализация через scipy: отдельная полоса 5–9 кГц, огибающая, динамическое снижение только в этой полосе при превышении порога (сила из ползунка)
- Reverb: Pedalboard Reverb только wet, с high-cut и low-cut на возврате, доля из ползунка
- Delay: длина по BPM (поле BPM опционально; если пусто, delay выключен), 1/8 или 1/4, фильтр на возврате, feedback небольшой
- Вокал нужно отполировать для рэпа: чёткость слов важнее «красоты», не перегружай реверб

## Шаг 3. Бит и баланс

- Если бит короче вокала, зацикли его под длину вокала; если длиннее, оставь как есть (допускается outro без вокала)
- «Место под вокал»: мягкий EQ-срез беата в диапазоне 1–4 кГц (около -1.5 дБ) и лёгкое динамическое приглушение этой полосы по огибающей вокала (до 1.5–2 дБ), только средняя полоса, низ и верх бита не трогай
- Баланс: вокал выше бита на N LU (из пресета, например +2 LU, настраивается ползунком), считать по integrated LUFS вокала и бита
- Следи за запасом по пику на сумме: оставь минимум 3 дБ headroom перед мастером
- Вокал и бит считаем выровненными по времени (вокал записан поверх бита); добавь поле сдвига в мс на случай рассинхрона

## Шаг 4. Мастеринг

- Подготовка перед Matchering: high-pass около 25 Гц, очень лёгкий bus-компрессор (1.5:1), контроль headroom
- Matchering: mg.process с референсом, выходы pcm24 (основной) и pcm16 (опционально), превью-файлы для A/B
- Проверь, что референс не слишком короткий и не моно-пустышка, при проблемах ясное сообщение
- Опция громкости: «как у референса» (по умолчанию) или «целевой LUFS» (например -14 для стриминга, -9 для громкого трека). Для режима цели после Matchering аккуратно подправь громкость и перепроверь true peak лимитером Pedalboard
- Режим 3 без референса: EQ по пресету → компрессор → нормализация до целевого LUFS → Limiter с запасом по true peak, итерации измерения 2–3 раза

## Шаг 5. Интерфейс (Gradio)

- Три вкладки по режимам
- Загрузка файлов, выбор референса из папки references/ или загрузка, выбор пресета
- Ползунки: уровень вокала (LU), де-эссер, reverb, delay, яркость вокала, место под вокал (duck), целевой LUFS, BPM, сдвиг вокала (мс)
- Результат: плеер, кнопка скачивания WAV 24 бит, опционально 16 бит и MP3
- A/B: «до / после» с выравниванием громкости, чтобы сравнение было честным и «громче» не казалось «лучше»
- Таблица чисел (LUFS, true peak, LRA, полосы) до и после, график спектра: оригинал, результат, референс
- Прогресс и понятные сообщения об ошибках (на русском)
- Интерфейс аккуратный, тёмная тема, без перегруза

## Шаг 6. Пресеты

В presets/ уже лежат JSON: trap_synthwave, rap_vocal, rock, clean_streaming. Подключи их, дай возможность редактировать значения и сохранять свои пресеты из интерфейса. Значения в файлах стартовые: донастрой их на тестах.

## Шаг 7. Запуск и качество

- requirements.txt, README (установка в одну команду, запуск одной командой, как добавить референсы)
- run.bat (Windows), run.command (macOS) и run.sh (Linux): создают venv при первом запуске, ставят зависимости, запускают app.py и открывают браузер
- Код модульный: core/audio_io.py, analysis.py, mixer.py, mastering.py, app.py; без дублирования, с докстрингами
- Тесты в tests/ на синтетическом аудио: анализ (LUFS синусоиды известного уровня), зацикливание бита, де-эссер, цепочки, экспорт, полный пайплайн
- Большие файлы (10+ минут) не должны падать по памяти
- Никаких вызовов в интернет во время работы, кроме установки зависимостей

## Критерии готовности

- Двойной клик по run-скрипту открывает интерфейс в браузере
- Вокал + бит + референс на входе, готовый мастер WAV 24 бита на выходе
- Результат по громкости и балансу частот заметно ближе к референсу
- Нет клиппинга, true peak в норме, нет артефактов от де-эссера и компрессии
- Все тесты проходят
- Никаких API-ключей и платных сервисов в проекте

Если что-то неясно, выбирай разумное значение по умолчанию, запиши решение в README и иди дальше. Спрашивай меня только если без ответа нельзя продолжить.
