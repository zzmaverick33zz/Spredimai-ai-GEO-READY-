# Scroll animated timeline

> A vertical milestone timeline that dynamically draws a progress line and reveals content cards on scroll.

- Author: [Waqar H. Syed](https://21st.dev/@ibrandify)
- Library: ibrandify UI
- License: mit
- Live preview: https://21st.dev/@ibrandify/components/scroll-timeline

## Install

```bash
npx shadcn@latest add "https://21st.dev/r/ibrandify/scroll-timeline?api_key=$API_KEY_21ST"
```

Requires a 21st API key (generate one at https://21st.dev/mcp) passed as `API_KEY_21ST`. Free accounts get a limited number of installs per day; unlimited on a paid plan — see https://21st.dev/pricing.

Full component directory: https://21st.dev/llms.txt
