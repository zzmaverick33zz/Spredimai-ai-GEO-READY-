# Zoom Parallax

> A smooth scroll effect where images zoom in at different speeds for a cinematic feel. Perfect for hero sections or storytelling layouts that need extra visual depth.

- Author: [Efferd](https://21st.dev/@efferd)
- Library: [Efferd UI](https://21st.dev/@efferd/library/efferd)
- License: unknown
- npm dependencies: framer-motion
- Live preview: https://21st.dev/@efferd/components/zoom-parallax

## Install

```bash
npx shadcn@latest add "https://21st.dev/r/efferd/zoom-parallax?api_key=$API_KEY_21ST"
```

Requires a 21st API key (generate one at https://21st.dev/mcp) passed as `API_KEY_21ST`. Free accounts get a limited number of installs per day; unlimited on a paid plan — see https://21st.dev/pricing.
