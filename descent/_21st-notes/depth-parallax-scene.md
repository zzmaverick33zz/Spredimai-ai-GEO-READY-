# Depth Parallax Scene

> A layered scene where consumer-supplied background/foreground layers travel at depth-proportional rates as the page scrolls and drift subtly with the pointer, used for parallax heroes and depth-of-field storytelling sections.

- Author: [Mehi](https://21st.dev/@rmahammad)
- Library: [Motiq](https://21st.dev/@rmahammad/library/motiq)
- License: MIT
- Tags: Parallax, Scroll Animation, Depth, Hero, Pointer
- Live preview: https://21st.dev/@rmahammad/components/depth-parallax-scene

## Install

```bash
npx shadcn@latest add "https://21st.dev/r/rmahammad/depth-parallax-scene?api_key=$API_KEY_21ST"
```
